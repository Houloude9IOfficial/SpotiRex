# Security

Please report possible vulnerabilities privately. Do not include credentials, access tokens, or personal listening data in a public issue.

Use **Report a vulnerability** in the repository's GitHub **Security** tab when private vulnerability reporting is available. If that option is unavailable, contact the repository owner privately through their [GitHub profile](https://github.com/Houloude9IOfficial) before sharing details. Private vulnerability reporting should be enabled before the repository is made public.

SpotiRex has no published release or supported security-update schedule yet. Reports affecting the current source are welcome.
