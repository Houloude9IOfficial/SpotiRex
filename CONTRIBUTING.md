# Contributing to SpotiRex

Thanks for helping make SpotiRex better. For bugs and ideas, open a GitHub issue with a clear description and, when useful, your macOS version and the music source involved. Please avoid sharing account details, tokens, or private listening data.

For a code change, fork the repository, make a focused branch, and open a pull request explaining what changed. Run `swift test` and `./Scripts/build-app.sh` locally before submitting. If your change affects playback sources or the display, include what you were able to check in the built app.

For a possible security vulnerability, follow [Security](SECURITY.md) instead of opening a public issue.
